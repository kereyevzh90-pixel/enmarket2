# Aiko Sarken — Интернет-магазин одежды

## Что это
Статический сайт магазина одежды (как Lamoda.kz) задеплоенный на Vercel. Товары хранятся в `products.json` и управляются через админ-панель. Авторизация пользователей через Supabase.

## Ссылки
- **Сайт:** https://enmarket2.vercel.app
- **Админка:** https://enmarket2.vercel.app/admin.html
- **GitHub:** https://github.com/kereyevzh90-pixel/enmarket2
- **Supabase:** https://xrcruomxqhqskhmcpops.supabase.co

## Как работает деплой
1. Код меняется локально → `git add / commit / push` → Vercel деплоит автоматически (~30 сек)
2. Admin добавляет/редактирует товар в `/admin.html` → коммит в `products.json` через GitHub API → Vercel деплоит
3. После пуша кода всегда делать `git pull --rebase` если remote опередил (admin мог сохранить товары)
4. При проблемах с кэшем браузера — Ctrl+Shift+R или открыть в инкогнито

## Структура товара в products.json
```json
{
  "id": "уникальный id",
  "name": "Название",
  "brand": "Бренд (необязательно)",
  "price": 15990,
  "oldPrice": 24990,
  "description": "Описание (необязательно)",
  "category": "women | men | kids",
  "sizes": ["XS", "S", "M", "L", "XL"],
  "color": "Чёрный",
  "badge": "Новинка | Хит | Акция | null",
  "image": "https://... (основное фото)",
  "images": ["https://...", "https://..."],
  "maxQty": 5,
  "inStock": true
}
```
- `image` — основное фото (показывается на карточке), для обратной совместимости
- `images` — все фото товара (массив, первое = основное)
- `maxQty` — максимальное кол-во штук в одном заказе (null = не ограничено)
- `badge: "Хит"` — товар попадает в карусель популярных (первые 4)

## Хедер
- Слева: кнопка меню (☰) + кнопка поиска (🔍)
- По центру: логотип `images/logo2.png` + текст "Aiko Sarken"
- Справа: избранное (♡, открывает панель избранного) + корзина (иконка Phosphor bag)
- Иконки из Phosphor Icons (SVG вставлены инлайн)

## Поиск
- Кнопка 🔍 в хедере открывает оверлей по центру экрана
- Поиск работает в реальном времени по названию, категории, бренду
- Закрыть: кнопка ✕ или клик на затемнённый фон или Escape
- Функции: `openSearch()`, `closeSearch()`, `doSearch(q)`

## Меню-drawer
- Кнопка ☰ в хедере открывает боковую панель слева
- Содержит ссылки на категории: Женщинам, Мужчинам, Детям, Распродажа
- При клике на категорию — фильтрует каталог и закрывает drawer
- Функции: `openDrawer()`, `closeDrawer()`, `setTabFromDrawer(val)`

## Карусель популярных товаров
- Расположена внутри каталога, под вкладками, до сетки товаров
- Показывает до 4 товаров: сначала с badge="Хит", потом остальные
- Высота 380px, скруглённые углы, не на всю ширину
- Листается стрелками или точками внизу, автолистание каждые 4 сек
- Если товаров нет — карусель скрывается (`display:none`)
- Функции: `initFeatured(products)`, `featSlide(dir)`, `featGoTo(idx)`

## Вкладки каталога
- Только три: **Женщинам / Мужчинам / Детям**
- По умолчанию активна "Женщинам"
- Активная вкладка подчёркнута чёрной линией 3px

## Фильтры (нижняя панель, Lamoda-стиль)
- Фиксированная панель внизу экрана: **Фильтры / Сортировка / Скидки**
- При нажатии выезжает панель снизу с фильтрами (Размер, Цвет, Цена, Сортировка)
- Кнопка "Применить" закрывает панель, "Сбросить" сбрасывает все фильтры
- Функции: `toggleBfilter()`, `closeBfilter()`
- `body` имеет `padding-bottom: 56px` чтобы контент не перекрывался баром

## Нижнее меню категорий (bottom-cats)
- Расположено под каталогом, над футером
- Вертикальный список: Все товары / Женщинам / Мужчинам / Детям / Распродажа
- Подкатегории раскрываются по клику
- Ниже списка — кнопка **"Войти"** (полная ширина страницы, Lamoda-стиль)
- После входа кнопка меняется на имя пользователя + меню "Мои заказы / Выйти"

### Функции авторизации (js/main.js):
- `initSupabaseSync()` — инициализация при загрузке, загружает избранное и корзину
- `toggleFav(id)` — добавить/убрать из избранного
- `toggleFavsPanel()` — открыть/закрыть панель избранного
- `syncCartOnLogin()` — мёрж локальной корзины с серверной при входе
- `saveCartToSupabase()` — сохранить корзину на сервер
- `placeOrder()` — оформить заказ (требует авторизации)
- `showOrders()` — показать историю заказов
- `toggleAlert(id)` — подписаться/отписаться от уведомления о цене

### Функции авторизации (inline script в index.html):
- `openAuth(view)` — открыть модалку ('register' | 'login')
- `closeAuth()` — закрыть модалку
- `switchAuth(view)` — переключить между регистрацией и входом
- `doRegister()` — регистрация через Supabase
- `doLogin()` — вход через Supabase
- `updateAuthBtn(user)` — обновить кнопку входа (показать promo card или user card)

## Корзина
- Хранится в `localStorage` + синхронизируется с Supabase когда пользователь вошёл
- Значок на иконке скрыт когда пусто
- Кнопка ✕ для удаления — в правом верхнем углу карточки
- Кнопка `+` блокируется когда достигнут `maxQty`
- Тост "Максимум N шт. в одном заказе" при попытке превысить лимит
- Кнопка "Оформить заказ" сохраняет заказ в Supabase (требует авторизации)

## Избранное
- Кнопка ♡ на карточке товара — добавляет в избранное (требует авторизации)
- Кнопка ♡ в хедере открывает боковую панель с избранными товарами
- На иконке ♡ в хедере показывается счётчик (красная точка с числом, как у корзины)
- Из панели можно добавить товар в корзину или убрать из избранного
- Функция `renderFavsCount()` обновляет счётчик на иконке (`id="favsCount"`)

## Уведомления о цене
- Кнопка 🔔 появляется на карточке товара при наведении
- Сохраняет подписку в таблицу `price_alerts`
- Фактическая отправка email требует Supabase Edge Functions (не реализовано)

## Загрузка фото в админке
- Drag & drop файлов прямо в зону загрузки, или клик для выбора
- Поддерживается несколько фото одновременно
- Фото загружаются в `images/products/` репозитория через GitHub API
- Кнопка ★ на превью — сделать фото основным
- Кнопка ✕ на превью — удалить фото из списка
- URL фото: `https://raw.githubusercontent.com/kereyevzh90-pixel/enmarket2/main/images/products/filename`

## Админка — первый вход
1. Открыть `/admin.html`
2. Ввести GitHub Personal Access Token (scope: `repo`)
3. Придумать пароль (мин. 4 символа)
4. Токен и пароль хранятся в `localStorage` браузера

## GitHub API — важные детали
- При каждом GET-запросе добавляется `?t=timestamp` для сброса кэша
- `saveToGitHub()` повторяет попытку до 3 раз при конфликте SHA (ошибка "does not match")
- Фото загружаются через `ghPut(..., rawBase64=true)` — без повторного кодирования
- После `git push` всегда делать `git pull --rebase` если remote опередил
