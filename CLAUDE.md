# EnMarket — Интернет-магазин одежды

## Что это
Статический сайт магазина одежды (как Lamoda.kz) задеплоенный на Vercel. Товары хранятся в `products.json` и управляются через админ-панель.

## Ссылки
- **Сайт:** https://enmarket2.vercel.app
- **Админка:** https://enmarket2.vercel.app/admin.html
- **GitHub:** https://github.com/kereyevzh90-pixel/enmarket2

## Как работает деплой
1. Admin добавляет/редактирует товар в `/admin.html`
2. Изменения коммитятся в `products.json` через GitHub API
3. Vercel видит новый коммит → автоматически деплоит (~30 сек)

## Структура файлов
```
index.html        — главная страница (каталог)
admin.html        — панель управления товарами
products.json     — база товаров (массив JSON)
css/style.css     — стили сайта
css/admin.css     — стили админки
js/main.js        — логика сайта (фильтры, корзина, рендер товаров)
js/admin.js       — логика админки (GitHub API, CRUD товаров)
```

## Структура товара в products.json
```json

  "id": "уникальный id",

  "category": "women | men | kids",

  "color": "Чёрный",
  "badge": "Новинка | Хит | Акция | null",
  "image": "https://...",
  "inStock": true

```

## Админка — первый вход
1. Открыть `/admin.html`
2. Ввести GitHub Personal Access Token (scope: `repo`)
3. Придумать пароль (только латиница, мин. 4 символа)
4. Токен и пароль хранятся в `localStorage` браузера

## Фильтры на сайте
- Категория, Размер, Цвет, Бренд, Цена, Сортировка
- Кнопки-таблетки (как Lamoda) — надпись меняется при выборе
- Левый сайдбар с деревом категорий
- Вкладки: Все / Новинки / Скидки / Женщинам / Мужчинам / Детям
